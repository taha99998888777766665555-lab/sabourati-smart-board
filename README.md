# سبورتي الذكية | Smart Board Pro

سبورة تفاعلية عربية للمعلمين (مشروع مستقل عن تطبيق «تعلّم مع أ/ طه محمد»).

- **الموقع المنشور:** فرع `gh-pages` (ملفان فقط: `index.html` و`.nojekyll`).
- **فرع `main` (هذا الفرع):** المصدر والاختبارات والتوثيق داخل `dev/`.
- بصمة MD5 للنسخة المعتمدة: `12b8030494f8fe01acbd8d17376ba0c8`.

## البناء والاختبار (من `dev/`)
```
python3 sources/build2.py          # يكتب build-out/smart-board-pro-merged.html
cd tests && npm i && node verify_merged.js
```
التفاصيل: `dev/README-RUN.txt` و`dev/HANDOFF-TO-CLAUDE.md` و`dev/PATH-FIX-NOTES.md`.

## قيود وملاحظات مفتوحة
- لم تُختبر على شاشة Riotouch الحقيقية بعد.
- ملاحظات أداء مفتوحة: X14 وY07 (المحو الجزئي بكثافة عالية جدًا)، وV06 (ذاكرة، متقلب).
- P2-١: لم يتكرر في النسخة الحالية ولا يُعد مُصلحًا بشكل مؤكد.
- اختبارات المراحل الأولى (T وM وL) قديمة ولم تُحدَّث؛ الانحدار المعتمد هو U وV وX وY وسلسلة Z.
